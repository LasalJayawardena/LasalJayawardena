## `// 01` The thesis

<img src="./assets/thesis-card.png" width="100%" alt="The model is not the finish line — build the intelligence around it" />

I’m **Lasal Jayawardena**, an AI researcher and doctoral researcher based in **Aberdeen, Scotland**.

A lot of AI progress is measured by what a model can generate from a prompt. I’m interested in the harder question:

> **What does it take to turn a powerful model into a genuinely capable intelligent system?**

For me, that means going beyond fluency.

Can the system **find the right evidence**? Can it **reason with prior experience**? Can it **evaluate its own output**? Can it **adapt a decision to context**? Can it stay **traceable, secure, and useful at scale**?

That is the thread connecting my work across **LLMs, retrieval, NLP, evaluation, adaptive decision systems, document intelligence, knowledge representation, and enterprise AI**.

A large-scale paraphrase resource designed around lexical and syntactic diversity, semantic similarity, and cleaner language data.

Exploring stronger evaluation through multiple LLM judges rather than treating one evaluator as ground truth.

## `// 07` Things I believe about AI

> **The next leap in AI will not come from generation alone.**

A few principles shape the work I want to do:

- **Intelligence needs evidence.** Answers are more useful when the system can show what it is reasoning from.
- **Retrieval is not just context stuffing.** Representation, similarity, memory, and selection are part of the intelligence problem.
- **Evaluation belongs inside the system.** Intelligent systems should be able to critique, compare, verify, and improve decisions.
- **Adaptation beats one-size-fits-all rules.** Context should change how a system behaves.
- **Production constraints are research constraints.** Security, governance, scale, latency, and reliability change what “good AI” means.
- **The best AI research expands what we can build.** A paper matters more when it changes the design space for real systems.

```text
more parameters      ≠ automatically more intelligence
more fluent output   ≠ automatically better decisions
more context         ≠ automatically better retrieval
more automation      ≠ automatically more trust

better evidence + better reasoning + better evaluation + adaptation
                                      ↓
                         more capable AI systems
```
